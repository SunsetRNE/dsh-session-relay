# dsh-session-relay 2.3.0

2.3.0 继续打磨右侧边栏：PR 页补文件改动、评论作者与「AI 审核」，远端列表提速；分支页能移除工作树并删除分支、批量清理遗留；侧栏页签与内容连成一块、密度再压两档，折叠改用 `ResizeObserver` 修掉旋转后的回归；邮箱、交接快照、会话详情改成结构化行。串行测试 410 全过。

## 亮点

- **PR 页**：详情看文件改动（总量与逐文件）、评审与评论（作者可点、长文折叠），点「AI 审核」拉起只读审核会话审最新改动；筛选与状态合并成一行、计数为 0 的筛选收起，「全部」常驻；已关闭列表里未合并 PR 显示「已关闭」，不再和打开列表混淆。
- **分支页**：标出被工作树占用的分支并给明确删除提示；二次确认后移除工作树并删除分支（只清 `.agents/worktrees` 下、干净、无 `.ACTIVE-SESSION` 的）；「清理遗留 N」子页多选后一次确认批量清理，未合并要额外勾选，服务端逐条重新校验。
- **密度与折叠**：页签栏与第一块内容连成一块（去掉分隔线与白缝），列表 / 卡片整体压缩两档；头部与窄侧栏继续收紧；页签折叠改用 `ResizeObserver` 量侧栏宽度（`dshaSv_wide` / `dshaSv_narrow`），旋转屏幕后重算，宽屏不再露快捷入口、窄屏不再露折叠页签。
- **长文本结构化**：邮箱 CI 通知拆成「标签 + 结果胶囊 + 仓库 / CI 号 / sha / 标题」元信息；交接快照拆成会话行与说明行；会话详情按基线重排（富文本摘要、字段胶囊、可换行芯片组）；汇报摘要与任务「最新」改轻量富文本。
- **列表与缓存**：侧栏远端列表 5 分钟缓存、并发请求合并、计数并行，客户端加缓存与详情悬停预取，减少重复拉取。

## 要求

DeepSeek Harness **0.2.2-rc.1 及以上**（`engines.dsh` / `peerDependencies` 见 `package.json`）；系统需已登录 `gh`。

## 安装

插件管理器 → 从 Release 安装本页唯一的 `dsh-session-relay-2.3.0.tgz`。

## 升级

- 从 2.2.0 覆盖安装；本次含服务端视图 / 动作（AI 审核、分支清理），装好后 `/relay reload`，再整页刷新（侧栏 `SIDEBAR_KIT 33`，关掉「协作」标签不会重载旧 chunk）。
- 侧栏仍是 9 个页签；折叠按侧栏宽度判断，旋转后即时重算；密度比 2.2.0 更紧。
- 任务库、邮箱与仓库守候数据沿用 2.2.0 格式，无需迁移。
- 2.2.0 的既有能力不变；已发布的 2.2.0 tag / Release 保持只读。
