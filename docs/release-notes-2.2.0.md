# dsh-session-relay 2.2.0

2.2.0 把右侧边栏扩成 9 页签的管理台：地图、PR、分支、问题、邮箱、更多各就各位，窄栏把地图 / PR / 分支 / 问题折进「更多」；仓库守候补上卫星环、设置四子页签与存量补报。串行测试 392 全过。

## 亮点

- **9 页签侧栏**：会话 / 任务 / 交接 / 地图 / PR / 分支 / 问题 / 邮箱 / 更多；窄栏（容器 <620px）自动折叠，页签懒挂载；PR / 问题 / 邮箱未读计数走 60 秒轻量刷新。
- **PR 页**：打开 / 已关闭列表与筛选、详情评审与评论、长文折叠；批准 / 请求修改 / 评论 / 关闭 / 重开只由用户点击（批准 / 关闭 / 重开二次确认），可把 PR 关联到本地任务；模型没有 GitHub 写入口。
- **分支页**：全工作区本地 / 远端分支，当前 / 默认 / 已合并状态与领先 / 落后，筛选与折叠；本地 / 远端删除逐条确认，远端要输入分支名。
- **问题页**：搜索、指派给我、标签筛选、关联任务标记；地图页单独展示地图票与本地票子，标题栏带计数。
- **仓库守候可视化**：输入框左侧卫星环 + 设置四子页签（总览 / 判定 / 触发 / 设置）+ 存量补报（`backlogHours`）。
- **更多页**：窄屏快捷入口（地图 / PR / 分支 / 问题 / 设置，带计数）、同步队列、仓库探测。

## 要求

DeepSeek Harness **0.2.2-rc.1 及以上**（`engines.dsh` / `peerDependencies` 见 `package.json`）；系统需已登录 `gh`。

## 安装

插件管理器 → 从 Release 安装本页唯一的 `dsh-session-relay-2.2.0.tgz`。

## 升级

- 侧栏页签从 4 个变成 9 个；旧的本机页签记忆回落到「会话」，「更多」收纳同步 / 仓库；地图 / PR / 分支 / 问题在宽侧栏有独立页签，窄栏在「更多」里。
- 地图与票子从「动态」迁到「地图」；邮箱独立成页；GitHub 账号与登录只在「设置」。
- 仓库守候数据与 2.1.0 兼容；`backlogHours` 默认关，只有登记时显式传才补报。
- 2.1.0 的既有能力不变。
