# UI 文案与语义基准线

用户 2026-11-07 定，所有界面（右侧边栏、对话里的「协作」面板、设置页）按这条扫：

1. **一个区块只表达一件事**；语义能合进按钮的就合进按钮（按钮文案 = 动作 + 必要风险词），不要再补一句说明复述按钮。
2. **该单独提示的单独提示**：错误、危险/不可逆确认、远端写入、状态变化，不埋进按钮或长说明里。
3. **文案精简**：一句能说清就不用两句；不复述标题/按钮、不写实现细节（工具名、字段名、内部 scope）、不写历史。
4. **双语同步**：zh / en 一起改，占位符 `{...}` 保留。
5. 自检：每个 hint ≤ 2 句；一个区块最多一组主操作；危险动作走二次确认，不靠长文案吓人。
6. **状态用动效，数据用包裹**：状态变化优先用动画（脉冲 / 转圈 / ✓），不要弹裸文字；数据、原始输出、超过 5 个字的裸文本不要整段平铺，包进胶囊 / 卡片 / 字段；预览截断，完整内容按需展开。错误、危险确认、远端写入仍用文字。

扫描范围：`client.js`（入口/设置/宿主文案）、`client.sidebar44.js` + `client.sidebar.*44.js`（右侧边栏外壳与页签 chunk）、`client.panel.js`（协作面板）。
