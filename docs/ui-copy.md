# UI 文案与语义基准线

用户 2026-11-07 定，所有界面（右侧边栏、对话里的「协作」面板、设置页）按这条扫：

1. **一个区块只表达一件事**；语义能合进按钮的就合进按钮（按钮文案 = 动作 + 必要风险词），不要再补一句说明复述按钮。
2. **该单独提示的单独提示**：错误、危险/不可逆确认、远端写入、状态变化，不埋进按钮或长说明里。
3. **文案精简**：一句能说清就不用两句；不复述标题/按钮、不写实现细节（工具名、字段名、内部 scope）、不写历史。
4. **双语同步**：zh / en 一起改，占位符 `{...}` 保留。
5. 自检：每个 hint ≤ 2 句；一个区块最多一组主操作；危险动作走二次确认，不靠长文案吓人。
6. **状态用动效，数据用包裹**：状态变化优先用动画（脉冲 / 转圈 / ✓），不要弹裸文字；数据、原始输出、超过 5 个字的裸文本不要整段平铺，包进胶囊 / 卡片 / 字段；预览截断，完整内容按需展开。错误、危险确认、远端写入仍用文字。

扫描范围：`client.js`（入口/设置/宿主文案）、`client.sidebar.js`（右侧边栏）、`client.panel.js`（协作面板）。

## 第一批（2026-11-07）

- 全插件 32 条长 hint 压到 1–2 句（zh/en 同步）：版本线、交接、常设授权、开发者模式、置顶、模型、模板、邮件、搜索、声明、核验、仓库、看板、唤醒、核验 watch 等。
- 去掉实现细节与复述（如 `peer_inspect`/`scope=all`、`peer_mail read`、重复的区块列表、历史说明）。
- 原生长下拉已在上一批换成自绘 picker；设置控件卡片化。

## 第二批（2026-11-07）

- 常设授权 / 开发者模式的边界提示已拆成独立一行（侧栏与面板同步）。
- 交接页：无草稿时不铺空编辑器；确认时自动保存未保存的说明（去掉「先保存草稿」拦截）。
- 任务详情：任务号胶囊点击复制、持有者一行点击开会话，去掉两个独立按钮。

## 第三批（2026-11-07）

- 交接页起草入口按主会话状态合一：正常「让主会话起草」，失败时同一个按钮变「插件整理草稿」（侧栏与面板同步）。
- 任务详情认领入口合一：只留「拉起认领」，去掉复制认领指令。
- 面板 Fold 复核：summary 只在折叠态显示、hint 只在展开态显示，不是同时出现，无需去重。

## 第四批（2026-11-07）：更新只用动画，不再用文字通知

- 成功 / 进行中反馈：协作面板与侧栏都改成一次短脉冲圆点（不弹字）；错误仍保留文字。
- 侧栏头部去掉「正在刷新 / X 分钟前」文字：忙碌时刷新图标转圈，新鲜度改成带 title 的彩色圆点。
- 写回 Projects 成功用脉冲，复制成功用 ✓；面板「正在加载」文字换成脉冲点。

## 第五批（2026-11-07）：数据变化高亮

- 协作面板看板：轮询后只给刚变化的会话卡片加 1.5s 底色渐隐高亮（整条 entry 比较；首屏/未变/notModified 不闪；reduced-motion 关闭）。
- 侧栏「会话」列表与「任务」列表都加了行高亮。

## 第六批（2026-11-07）：同步行与仓库状态行精简

- 任务页 / 动态页 / 设置页共用的同步行只显示「同步 · 空闲 / 队列 N / 已暂停 / 未启用」；仓库名、未知/失败细节收进 title；队列为 0 不再显示数字。
- 仓库状态行只显示「已探测 / 探测失败」，仓库名收进 title；探测失败原因仍用文字。

## 第八批（2026-11-07）：协作面板概览压缩

- 版本线改成摘要卡：`main` / `HEAD` / 检查点 / 测试 / 未发布用胶囊，正文两行预览 + 展开全文。
- 快速交接、计数、自动唤醒行用轻卡片包裹，不再裸文字平铺。

## 第九批（2026-11-07）：会话页包裹

- 会话页版本线改成摘要卡：胶囊 + 两行预览 + 展开全文，不再铺整段。
- 会话卡片汇报摘要放进小卡，提交 / 分支 / 工作树用胶囊包裹，底行不再是一串纯文本。

## 第十批（2026-11-07）：状态动效 + 包裹基线

- 状态变化：成功 / 进行中用脉冲 / 转圈 / ✓，不弹文字；错误仍用文字。
- 数据与原始输出：版本线、提交 / 分支、session id、汇报摘要、计数等用胶囊 / 卡片 / 字段包裹；长文本两行截断 + 展开，不裸露整段。
- 裸文本尽量 ≤ 5 字（标签、计数）；超出的进 UI 组件。

## 第十一批（2026-11-07）：交接与核验页包裹

- 核验：每条记录独立小卡，状态胶囊 + 两行截断。
- 任务状态：why / 备注从小字改成小卡；交接历史时间、来源、目标用胶囊。
